# Proxy Generate Tool

为高码率或高分辨率素材生成统一规格的低码率代理视频和可选音频代理。

## 作用

降低 Shot Detection、预览和部分分析任务的读取成本，保留原始时间轴映射。

## 实现边界

输出必须记录编码参数和与源素材的时间对应关系；不能覆盖原始 Asset。

## 当前实现

`video.proxy-generate@1.0.0` 已实现为 CPU Tool：

- 输入一个 `VIDEO_SOURCE`；
- 使用 FFmpeg 输出 H.264/AAC MP4；
- 支持 4K（3840×2160）、2K（2560×1440）、1080p（1920×1080）和 720p（1280×720）；
- 竖屏素材自动交换宽高上限，且不放大低于目标规格的原视频；
- 输出统一为 30 FPS；
- 各档使用受控 CRF 20/21/22/23，在清晰度和体积之间平衡；
- 使用 `yuv420p` 和 `faststart` 保证浏览器兼容性；
- 输出不可变 `VIDEO_PROXY` Artifact、SHA-256 和编码元数据。
